19// We convert all values to the appropriate unsigned integers to avoid warnings about comparing differently signed integers.
20// In theory, this performs two unnecessary casts when comparing two signed integers.
21// In practice, any decent compiler will just optimize this away by reinterpreting the bits of the signed integer.
22// Then it's just a simple matter of zero-extending the smaller integer to the larger integer.
23//
24// To that end, we implement a little wrapper for conveniently casting to each integer's unsigned type (if it isn't already).
25template<typename Integer_>
26constexpr auto as_unsigned(Integer_ x) {
27 static_assert(std::is_integral<Integer_>::value);
28 if constexpr(std::is_unsigned<Integer_>::value) {
29 return x;
30 } else {
31 return static_cast<typename std::make_unsigned<Integer_>::type>(x);
32 }
33}
