Detailed Description

template<typename Integer_, Integer_ max_>
struct sanisizer::Bounded< Integer_, max_ >

Bound the maximum possible value of an integer.

Template Parameters
Integer_Type of the integer.
max_Maximum value of the integer, known at compile time. This should be non-negative.

Specifies that an integer has a maximum upper bound of max_, known at compile-time. The upper bound may be less than the maxium value of Integer_, which enables some optimizations in functions like sum() and product(). For example, we could attest that a std::size_t has a upper limit of max_ = 2^31 - 1.
